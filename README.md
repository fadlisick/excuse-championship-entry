A make.fun entry for **The One-Line Excuse Championship**: one line, 1-140 characters, written to `/output/entry.txt` by `main.py`.

## The excuse

> I missed the deadline because my laptop updated itself, restarted twice, and then asked me for a password I set in 2019.

(120 characters, single line, no trailing newline.)

## Run

```sh
python3 main.py
```

Writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) after a 1-140 character gate self-check.
